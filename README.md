# 本源 Arche

英语单词溯源词典。把四级、六级、专升本、专业四级、辽宁专升本词表合成一份词库，沿着印欧语词根往上走。

仓库：https://github.com/3668708696cjw-web/arche-word-origin

## 本机运行

需要 [Node.js 22](https://nodejs.org/)。

```bash
git clone https://github.com/3668708696cjw-web/arche-word-origin.git
cd arche-word-origin
npm install
npm run dev
```

浏览器打开本地地址（一般是 http://localhost:8080）。
